# GIC Ndjeke — application Android

Carnet de terrain des membres du GIC Ndjeke Prospérité, relié au serveur farmOS du groupement
(tableau de bord, saisie hors connexion, pages du GIC).

- Code de l'application : `src/` (JavaScript, regroupé par esbuild dans `www/app.js`), `www/` (HTML, CSS, images)
- Projet Android natif (Capacitor 8) : `android/`
- Compilation et signature : `.github/workflows/android.yml` (GitHub Actions)
- Publication pas à pas : **PUBLICATION.md**
- Textes et visuels du Play Store : `store/`
